# Didactopus v0.1.2

This compatibility release updates Epistemap to `v0.1.0a5` and corrects graph
quality analysis for educational packs.

## Included

- Invalid pack input is returned as `invalid_input`; graph analysis is marked
  `not_run`, with a null graph warning count rather than a misleading zero.
- YAML roots and pack entries are checked before graph analysis; malformed roots,
  list entries, prerequisite values, and dangling prerequisite IDs are reported.
- Cycle members and acyclic descendants blocked downstream are reported
  separately using strongly connected components.
- Direct prerequisite concentration is labeled accurately and stays advisory.
- Repeated prerequisite links do not inflate the unique edge count; longest
  chain is unavailable for cyclic graphs.
- The [graph prerequisite analysis guide](../graph-prerequisite-analysis.md)
  documents output status and limits.

## Validation

- `pytest -q`: 312 passed.
- Ruff checks passed for the changed source and test files.
- GroundRecall and CiteGeist consumer suites were exercised against the updated
  Epistemap source before this release was prepared.
