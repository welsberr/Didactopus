# Didactopus v0.1.1

This compatibility release aligns Didactopus with Epistemap `v0.1.0a2` and the
unified confidence-overhaul contract.

## Included

- Epistemap dependency pin updated to `v0.1.0a2`;
- typed candidate and citation extraction assessments with legacy alias
  compatibility;
- canonical `evidence_coverage` naming for weighted evidence, stop criteria,
  and exports, with deprecated confidence aliases retained;
- duplicate-evidence safeguards and missing-versus-explicit-zero preservation;
- response calibration reports separating selected-answer correctness,
  probability of truth, abstention, discrimination, and evidence coverage.

## Compatibility

Legacy confidence aliases remain readable and emit deprecation warnings where
implemented. Ambiguous legacy zero values remain reported rather than rewritten.
